# 🧮 Calculator Web App

A clean, dark-themed calculator built using **HTML, CSS, and JavaScript**.

## Features

- Basic operations: Addition, Subtraction, Multiplication, Division
- Percentage and sign toggle (+/-)
- Expression history display
- Keyboard support
- Smooth animations
- Error handling (divide by zero)

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## How to Run

1. Clone the repository
2. Open `index.html` in any browser

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `0-9` | Number input |
| `+ - * /` | Operators |
| `Enter` | Calculate |
| `Escape` | Clear |
| `Backspace` | Delete last digit |
